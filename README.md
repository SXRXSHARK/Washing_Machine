Innovative Washing Machine

An embedded control system for a washing machine, built with ease of use, safety, and effective cycle management in mind.

Features

On/Off control with audio feedback (distinct melodies for power on/off)
Temperature selection via potentiometer (40°C / 50°C / 60°C)
Wash cycle selection via potentiometer (Cottons, Synthetics, Delicates, Quick Wash)
Multi-coloured LED and LED indicators for visual confirmation of selected settings
Door-closed detection using a light-detector reflector (LDR) before a cycle can start
Seven-segment countdown timer with LED progress/completion indicators
Emergency stop button (manual reset required via start/stop button)
Real-time status reporting over a serial interface
